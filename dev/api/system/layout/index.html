Runes2P.KineticUnknown — Type
KineticUnknown(name, grid; scale=1, nonnegative=false)

Distribution function on the kinetic grid grid, one value per momentum cell at each radius (e.g. :hot_tail_distribution). The momentum grid may differ between radii. A distribution is normally declared without a lower limit: negative values produced by the discretization belong to the scheme, not to the Newton steps.

Runes2P.LowerLimit — Type
LowerLimit(; value=0, tolerance=0, reference=nothing)

Lower limit of an unknown, enforced on Newton steps (DREAM damps the Newton update to keep selected unknowns above a tenth of their value, MaximalPhysicalStepLength in src/Solver/SolverNonLinear.cpp:441-524): every entry stays at or above value - tolerance * reference value, where the reference value is the radial unknown reference (one component) at the same radius, or the unknown's own scale when reference is nothing, or the sum of the magnitudes of the components of the entry's group at the same radius when reference is :group (the charge states of one ion species, RadialUnknown with groups). Declared on the unknown with nonnegative = true (value 0, tolerance 0) or nonnegative = LowerLimit(...), e.g. RadialUnknown(:ion_densities; components=3, nonnegative=LowerLimit(tolerance=1e-12, reference=:total_electron_density)). Scalar unknowns take no reference. An unknown that can sit at exactly 0 (an empty charge state) needs a positive tolerance: with tolerance 0 a round-off negative update of an entry at its limit fails the Newton step (:below_lower_limit), and shorter time steps do not help.

value is an absolute limit in the units of the unknown, such as the floor of a temperature: RadialUnknown(:cold_electron_temperature; nonnegative=LowerLimit(value=0.5)). A Newton update loses at most the fraction max_reduction of the distance to the limit, so an iterate approaches the floor and does not cross it, and a step whose solution lies below it does not converge and is refused. The temperature unknown of a PlasmaFromUnknowns takes the floor of that source as its limit without a declaration, and the larger of the two values where both exist. A temperature that only fluid terms read takes the default floor DEFAULT_TEMPERATURE_FLOOR without a declaration (fluid_temperature_floors); a declared limit is kept as it is.

Runes2P.RadialUnknown — Type
RadialUnknown(name; components=1, scale=1, nonnegative=false, groups=nothing)

Unknown with components values at each radius (e.g. :electric_field, or :ion_densities with one component per charge state). groups splits the components into consecutive ranges, such as the charge states of each ion species (component_groups).

Runes2P.ScalarUnknown — Type
ScalarUnknown(name; scale=1, nonnegative=false)

Unknown with one value for the whole system (e.g. :plasma_current). scale is its reference magnitude; nonnegative declares a LowerLimit.

Runes2P.UnknownLayout — Type
UnknownLayout(radial_grid, unknowns; scalars=:last)

Positions of the unknowns (a list of ScalarUnknown, RadialUnknown and KineticUnknown) in the state vector. Each radius owns one contiguous block, with the radial and then the kinetic unknowns in declaration order; the scalar unknowns form one block after the radius blocks (scalars = :first places it before them, which only serves to check that no code depends on the order). Kinetic unknowns must live on radial_grid. The layout is immutable; adding an unknown builds a new layout.

source
Runes2P.component_groups — Method
component_groups(unknown::RadialUnknown)

The groups of the components of a radial unknown, consecutive ranges that split 1:components: the charge states of each ion species for the ion densities (ion_densities_unknown), one group of all components otherwise. A LowerLimit with reference = :group and a Tolerance with a group part are relative to the sum over the group of an entry.

source
Runes2P.copy_unknowns! — Method
copy_unknowns!(u_to, layout_to, u_from, layout_from)

Copy the values of every unknown present in both layouts, matched by name. The sizes, the radial grid, the momentum grids of a kinetic unknown and the component groups of a radial unknown (the ion species) must agree. Two species with the same count of charge states that trade places are not detected. Returns the names copied. This is how a state is carried to a layout with another order or with unknowns added or removed (restarts).
